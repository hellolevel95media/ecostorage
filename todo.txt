6) GITHUB ACTIONS SECRETS — AUTOMATED DB BACKUPS
   Why: the backup workflow (.github/workflows/backup.yml) is already built
   but needs credentials to actually run.
   Steps:
   - In the GitHub repo: Settings > Secrets and variables > Actions.
   - Add secret SUPABASE_PROJECT_REF (the project ref from the Supabase URL).
   - Add secret SUPABASE_DB_PASSWORD (the Postgres password, from Supabase
     Project Settings > Database).
   - The workflow runs daily at 03:00 UTC automatically; you can also trigger
     it manually from the Actions tab ("Run workflow").
   - Backups land as a downloadable artifact on each workflow run (kept 30
     days). For longer retention, consider adding an upload step to S3/Backblaze
     later.

7) ADMIN 2FA — ENABLE ON YOUR OWN ACCOUNT
   Why: the feature is built, but it isn't "on" until you personally enroll.
   Steps:
   - Log in to /admin.
   - Go to the "Security" tab in the sidebar.
   - Click "Enable 2FA", scan the QR code with an authenticator app (Google
     Authenticator, Authy, 1Password, etc.), enter the 6-digit code to confirm.
   - From then on, sign-in will ask for a code after your password.
